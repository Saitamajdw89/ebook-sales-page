# Ebook sales page – Make Money Online for Free (James Daniel Wiley / Hyperium)

Static site: `index.html` + `images/`. No build step. Upload the whole folder to any static host (e.g. GitHub Pages).

To add a link: in index.html find the "FREE RESOURCES & TOOLS" section, copy one `<div class="link-card">` block, paste it before "ADD NEW LINK CARDS ABOVE THIS LINE", and edit the title, description and href.
